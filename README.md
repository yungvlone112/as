# Ms.Bimbo — сайт (этап 1)
Статичный сайт для GitHub Pages. Залей все файлы в корень репозитория,
затем Settings -> Pages -> Deploy from branch (main, /root).

- Демо-вход работает сразу, данные хранятся в браузере.
- Этап 2: впиши botName и authUrl в data.js (CONFIG), подключи Worker с проверкой подписки.
- Сайт закрыт от индексации (noindex). Откровенные материалы на Pages не размещай.
